Building This Portfolio

This website is a personal project that I created to document my journey, experiences, and professional growth. With no previous background in web development, I taught myself Python and Django to build this portfolio from the ground up. Through this process, I learned how to structure web applications, manage content, work with databases, use Git for version control, and deploy a live website. There were many errors, challenges, and moments of frustration along the way, but the most rewarding part has been seeing an idea transform into reality.

Started No coding background.
Learning Learned Python, Django, HTML, CSS, databases, and Git version control.
Challenges Faced errors, broken layouts, server problems, and debugging challenges while building.
Improvement Learned from mistakes, improved my design, and developed problem-solving skills.
Achievement Created and deployed my own portfolio website from an idea into reality.
